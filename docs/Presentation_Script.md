# Presentation Script (5-10 Minutes)

## Slide 1: Title Slide
**Visual**: Project Title, Student Name, Course/Capstone Name.
**Script**: "Hello everyone. Welcome to my capstone presentation on 'GPU-Accelerated Image Enhancement and Artistic Sketch Generation'."

## Slide 2: The Problem
**Visual**: A high-resolution image, CPU core icon struggling.
**Script**: "Image processing involves calculating new values for millions of pixels. A 4K image has over 8 million pixels. Applying complex filters like edge detection or convolutions sequentially on a CPU is time-consuming. Modern CPUs only have a handful of cores, limiting their ability to process all these pixels simultaneously."

## Slide 3: The Solution (CUDA)
**Visual**: NVIDIA GPU diagram, thousands of tiny threads.
**Script**: "The solution is GPU parallelism. NVIDIA's CUDA architecture allows us to offload this work to the Graphics Processing Unit. Instead of 8 or 16 CPU cores, we can utilize thousands of lightweight GPU threads, assigning one thread to compute exactly one pixel of the output image."

## Slide 4: Project Features
**Visual**: Collage of filters (Blur, Sobel, Sharpen, Contrast).
**Script**: "In this project, I wrote custom C++ CUDA kernels from scratch to implement several classic filters: Grayscale, Gaussian Blur, Sobel Edge Detection, and Sharpening. I also built a baseline CPU implementation using OpenCV to act as our benchmark."

## Slide 5: The Pencil Sketch Pipeline
**Visual**: Flowchart of the Sketch effect (from Architecture docs).
**Script**: "The highlight of the image processing is the Pencil Sketch pipeline. It involves four distinct steps: converting the image to grayscale, inverting the colors, applying a heavy Gaussian blur to the inverted image, and finally blending the blurred image with the original grayscale using a Color Dodge algorithm. By chaining these kernels together on the GPU, we avoid costly memory transfers back to the CPU between steps."

## Slide 6: CUDA Optimizations Used
**Visual**: Bullet points of CUDA features.
**Script**: "To ensure maximum performance, I utilized a 2D Thread Grid mapped exactly to the image coordinates. I also utilized 'Pinned Memory'—or page-locked memory—on the CPU side, which significantly increases the bandwidth speed when transferring the image over the PCIe bus to the GPU."

## Slide 7: Performance Results
**Visual**: Bar charts generated by the Python script showing execution time and speedup.
**Script**: "As you can see in these benchmarks, the GPU implementation dramatically outperforms the CPU. [Point to graph]. The convolution operations like Gaussian Blur and Sobel Edge Detection saw massive speedups, often executing 20 to 50 times faster on the GPU. The Pencil Sketch pipeline also saw significant gains due to keeping intermediate data in VRAM."

## Slide 8: Conclusion & Demo
**Visual**: Live demo screenshot or repo link.
**Script**: "In conclusion, GPGPU is highly effective for image processing. The resulting code is available on my GitHub. I will now run a quick live demonstration showing the compilation and execution of the program. Thank you, I'll now take questions."
